# Container Query port logos

These local assets keep the port selector independent of external image requests.

- `northport-n4.svg`: supplied as `media/N4_Kaleris_logo.webp`. Its contents are SVG, so the app copy uses the correct extension.
- `westport.webp`: supplied as `media/etplogo.webp`.
- `westport-transparent.png`: background removed from the supplied Westport logo using the built-in imagegen tool; used in the header circle and prompt card.
- `kuantan.png`: Kuantan Port's header logo, from https://www.kuantanport.com.my/wp-content/uploads/2022/09/KP-black.png.
- `penang.png`: Penang Port's header logo, from https://www.penangport.com.my/penangport.com.my/media/2021/logo.png.
- `kuantan-icon.png`, `penang-icon.png`: transparent cutouts of the symbols attached by the user, prepared with the built-in imagegen tool. These are only used in the header circles; the full logos above remain in the prompt cards.

The Northport and Westport originals remain in `media`.

The image editing prompts are recorded in [image-edit-prompts.md](image-edit-prompts.md).
